# Adaptive AAC Platform

## Project Overview

Adaptive AAC Platform is a web-based Augmentative and Alternative Communication (AAC) application designed for children with moderate Cerebral Palsy (GMFCS Level III and IV). The platform aims to provide a simple, affordable and easy-to-use communication system that helps children express their needs using images and recorded voice.

This project is inspired by the Awaaz AAC application but focuses on providing a simplified interface suitable for the target users.

---

# Problem Statement

Commercial AAC applications are often expensive and contain many advanced features that may not be necessary for every child. Many families cannot afford these applications.

This project aims to build a simple, accessible and affordable AAC platform that allows children to communicate using customized picture cards and recorded voice.

---

# Target Users

- Children with Moderate Cerebral Palsy (GMFCS Level III & IV)
- Parents / Caregivers
- Therapists (Future Scope)

---

# Project Goal

To develop an easy-to-use AAC platform where caregivers can create personalized communication cards using real-world images and recorded voice. The application should provide a clean interface that children can use independently with minimal assistance.

---

# Core Features

- Login
- Child Profile
- Home Screen
- Category Management
- 3 × 3 Communication Grid
- Capture Image using Camera
- Record Voice
- Play Voice
- Delete Card
- Edit Card
- MongoDB Database
- Responsive Design
